# Project Skills

This folder keeps the human-readable skill documents for maintaining BintangToba.

## Skill documents

- `portfolio-maintenance.md` — portfolio behavior, language/theme rules, and quality checklist.
- `design-governance.md` — visual system, file grouping, component gateway, and anti AI slop rules.
- `engineering-integrity.md` — honest engineering, clear error handling, and verification discipline.

## Runtime skill locations

OpenCode and compatible agents should load the executable skill definitions from:

- `.opencode/skills/bintangtoba-portfolio/SKILL.md`
- `.opencode/skills/bintangtoba-design/SKILL.md`
- `.opencode/skills/bintangtoba-engineering-integrity/SKILL.md`

Mirror copies are also kept under `.agents/skills/` and `.agent/skills/` for compatibility.
